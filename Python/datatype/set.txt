Set - set() {}
A set is an unordered collection of unique elements. It is defined using curly braces {} or the set() constructor. Sets are mutable, meaning you can add or remove elements from them.
Create a Set
To create a set, you can use curly braces {} or the set() constructor. Note that sets do not allow duplicate elements, and the order of elements is not guaranteed.
Example
Create a Set using curly braces:
myset = {"apple", "banana", "cherry"}
print(myset)
Output:{'banana', 'cherry', 'apple'}
Example
Create a Set using the set() constructor:
myset = set(["apple", "banana", "cherry"])
